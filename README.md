# 📸 Wedding Photographer

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=github)](https://artemishchenkogit.github.io/wedding-photographer-kava-java-team-3/)
[![Source Code](https://img.shields.io/badge/Source-Code-blue?style=for-the-badge&logo=github)](https://github.com/artemishchenkoGIT/wedding-photographer-kava-java-team-3)

A responsive, modern landing page for a professional wedding photography
service. The website is designed to showcase photography portfolios, highlight
services and pricing packages, and provide convenient contact and booking
options for potential clients.

## ✨ Features & Functionality

- **Responsive Design:** Mobile-first, fully adapted for smartphones, tablets,
  and desktop displays.
- **Interactive Portfolio Gallery:** Showcases high-resolution photography with
  optimized loading and smooth transitions.
- **Services & Pricing Cards:** Clear breakdown of photography packages,
  services offered, and details.
- **Contact & Booking Form:** User-friendly form allowing visitors to inquire
  about dates and services.
- **Cross-Browser Compatibility:** Consistent layout and performance across
  modern browsers (Chrome, Safari, Firefox, Edge).

## 🚀 Getting Started Locally

To run and build this project locally, make sure you have
[Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository

```bash
git clone https://github.com/artemishchenkoGIT/wedding-photographer-kava-java-team-3.git
```

### 2. Navigate to the project directory

```bash
cd wedding-photographer-kava-java-team-3
```

### 3. Install dependencies

```bash
npm install
```

### 🛠️ Development Mode

Runs the application in development mode with a local server and live-reloading:

```bash
npm run dev
```

### 📦 Production Build

Builds the app for production to the output folder (`dist` or `build`). It
optimizes assets for performance and produces production-ready bundles:

```bash
npm run build
```

## 🔌 API Integration

- **API Documentation:**
  [Swagger API Docs](https://wedding-photographer.b.goit.study/api-docs/)
- **Base URL:** `https://wedding-photographer.b.goit.study/api`

### Used Endpoints:

- `GET /categories` — List of photography service categories
- `GET /wedding-photos` — Portfolio photo gallery (accepts query parameters:
  `page`, `limit`, `categoryId`)
- `GET /feedbacks` — Customer reviews and testimonials
- `POST /orders` — Submitting a contact/booking form request
